# OpenImport

Import and export for Magento 2 and Mage-OS, free and MIT.

OpenImport puts profiles, column mapping, value transforms, a dry run that previews every change, schedules and
remote sources (SFTP, FTP, URL) in front of Magento's own import engine. Magento does the writing, so imported data is
exactly what core import would produce, and upgrades keep working.

**Status:** in development (milestone M0). Nothing to install yet. Follow the
[roadmap](https://github.com/iranimij/openimport/milestones).
