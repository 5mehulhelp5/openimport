# Security policy

Supported: the latest 1.x release.

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on this repository (Security tab). Do not open a public issue. You will get a reply within 7 days. There is no bug bounty.

OpenImport reads files from remote servers and writes into your catalog, so reports about server-side request forgery, XML external entities, path traversal, archive bombs, spreadsheet formula injection, credential leaks and missing ACL checks are especially welcome.
